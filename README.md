Personal website for the stories and poems of Dr. [Mother's Name].

**Live site:** [add link once published]

## Structure

```
index.html      Home page
stories.html    List of stories
poems.html      List of poems
about.html      About the author
404.html        "Page not found" page
style.css       All styling (colours are at the top)
stories/        One HTML file per story
poems/          One HTML file per poem
```

## Adding a new piece

1. Copy an existing file in `stories/` or `poems/` and rename it (lowercase, dashes, no spaces).
2. Update the title, date and text.
3. Add a link to it on `stories.html` or `poems.html`, and on `index.html`.
